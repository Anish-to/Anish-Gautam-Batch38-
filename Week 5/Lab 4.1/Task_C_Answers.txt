TASK C: MAPPING STATIC TEXT AND DATA SECTION BOUNDS

Question 1:
What does elf64-........... reveal about hardware architecture, address sizing, and byte serialization?

Answer:
The executable is identified as elf64-littleaarch64.

ELF64 means that the executable uses the 64-bit Executable and Linkable Format.
AArch64 means that it is compiled for the 64-bit ARM architecture.
The word "little" means that the system uses little-endian byte ordering, where the least significant byte is stored at the lowest memory address.

Start: 0x0000aaaaaaac0000
End:   0x0000aaaaaaac0020

Question 5:
Analyze the .data versus .bss sections. Which one occupies the lower memory range?

Answer:
The .data section is:

0x0000aaaaaaac0000 - 0x0000aaaaaaac0020

The .bss section is:

0x0000aaaaaaac0020 - 0x0000aaaaaaac0028

Therefore, the .data section occupies the lower memory range, and the .bss section starts immediately after the .data section.
