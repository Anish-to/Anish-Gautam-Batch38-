# Week 2

This folder contains the practical work completed during Week 2 of the module.

## Lab 2

This week's work focuses on C programming basics and the GCC compilation process.

The main activities include:
- Creating and running C programs.
- Taking input from the user.
- Using formatted output.
- Understanding return values and exit status.
- Using the `echo $?` command to check the exit status of a program.
- Understanding the four stages of GCC compilation.
- Generating preprocessed, assembly and object files.
- Linking an object file to create an executable program.

The files in this folder contain the programs and compilation files created during the lab.
