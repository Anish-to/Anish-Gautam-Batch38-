# Week 1

This folder contains the practical work completed during Week 1 of the module.

## Lab 1

The work in this week focuses on the basics of C programming and working with programs in the Linux environment.

The main activities include:
- Writing and running basic C programs.
- Using GCC to compile C programs.
- Understanding basic input and output.
- Creating and executing compiled programs.
- Practicing basic Linux terminal commands.

The files in this folder contain the programs and outputs completed during the lab sessions.
